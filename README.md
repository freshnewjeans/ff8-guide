# Final Fantasy VIII Remastered — Trophy Tracker & Guide

A beautiful macOS-style, light-mode trophy-hunting companion for **Final Fantasy VIII Remastered**, so you can get the Platinum without missing any of the 29 missable trophies.

## Features
- All **35 trophies** (1 Platinum · 4 Gold · 16 Silver · 14 Bronze), grouped into **6 walkthrough phases** in play order
- Trophy tiers shown as **real SVG badge icons** (gold / silver / bronze / platinum), not just words
- Detailed **"How to unlock"** guide for every trophy, including missable draw-GF warnings
- **Game Guide** page: Junction system primer, every GF's location (with the missable ones flagged), Triple Triad rules, and real gameplay screenshots of key locations
- Tick trophies as you earn them — progress saves in your browser (no login, no account)
- Light macOS theme, fully mobile-ready for iPhone Safari
- Fully responsive, no-build static HTML

## Use
Open `index.html` in any browser, or use the live GitHub Pages link:
**https://freshnewjeans.github.io/ff8-guide/**

Trophy list verified against public FF8 Remastered sources. Screenshots are real gameplay captures used for reference.
